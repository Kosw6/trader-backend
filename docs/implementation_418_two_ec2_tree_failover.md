## 실제 테스트 경로

운영 Nginx의 공개 가상호스트는 변경하지 않았다. origin의 **127.0.0.1:19420**에만 별도 QA upstream을 추가해 B를 primary, A를 backup으로 설정했다. QA 클라이언트는 암호화 SSM 터널로 A와 이 QA 주소에 연결했다. 응답의 QA upstream 헤더로 연결 대상의 사설 주소를 확인했다.

프론트의 실제 `connectTeamTree`, `createTeamTreeReloader`, `reconcileTeamTreeSelection` 모듈을 그대로 실행했다. 쿠키 헤더를 지원하는 stdin 기반 Python WebSocket 어댑터를 사용했으며, 실제 브라우저 DOM 조작 테스트는 아니다. 임시 QA 그룹의 생성/삭제 외 기존 그룹·노트·멤버십을 변경하지 않았다. 조회는 READY/변경 이벤트에 의해 발생하며, 주기적 트리 폴링으로 테스트를 우회하지 않았다.
